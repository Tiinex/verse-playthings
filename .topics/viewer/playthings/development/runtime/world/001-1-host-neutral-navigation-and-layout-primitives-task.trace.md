# Host-Neutral Navigation And Layout Primitives

## Objective

Qualify deterministic navigation and placement mathematics without choosing unresolved floor ordering or interpreting authored PNG topology.

## Scope

- Build an immutable grid/portal graph with cardinal movement, explicit door-edge state and stairs between supplied surfaces.
- Use bounded deterministic least-cost routing; distinguish blocked endpoints, unreachable topology and search-budget exhaustion.
- Sample movement in presentation time, keeping cross-surface transitions explicit rather than drawing fictitious diagonal movement.
- Provide stateless visual variation, explicit capacity estimates, incremental fixed reservations and topological NESW masks.

- Existing footprint growth is reported as a repacking requirement, not silently applied. Layout replay requires the same insertion history/reservations.
