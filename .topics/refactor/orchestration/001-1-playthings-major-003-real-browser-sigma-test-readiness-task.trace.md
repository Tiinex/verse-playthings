# Playthings Major 003 — Real Browser Sigma Test Readiness

## Objective

Turn the current Verse Playthings experience candidate into a genuinely viewable, technically qualified candidate that Sigma can open through the real App/Site browser host and evaluate as a human.

## Done Criteria

- The current Verse Playthings candidate is reconciled against the exact carried App/Core/Site host contracts without weakening provenance, source truth, or fail-closed behavior.
- Verse-local defects discovered by qualification are repaired inside `verse-playthings` with focused regression coverage.
- The real Site React/Vite browser path starts and exercises the actual current Playthings interaction contract, including timeline/history, Root Gate, exit back to Viewer, and browser-fullscreen behavior where supported.
- Stale smoke assumptions are reported precisely rather than treated as Verse defects; sibling App/Site/Core changes are not made without separate authority.
- A concise Sigma launch/observe test card is returned only after a genuine real-browser PASS on the exact candidate.
- The return preserves exact blockers if the candidate cannot yet reach Sigma rather than manufacturing a synthetic PASS.

## Scope

Major 003 is a readiness/qualification major, not a feature-expansion major. It may repair Verse-local presentation, interaction, accessibility, runtime, package, fixture, or test defects needed to make the current candidate honestly testable. It does not add RPG systems, new product concepts, broad graphics work, release/publication work, or unrelated Viewer features.

## Known Starting Observations

- Current App host source still renders a host-level `Back to Viewer` control while current Playthings also renders its own Root Gate/Back control.
- Current Site `tools/browser-smoke.py` still asserts the older `2 / 2 declared historical moments` text and drives Fullscreen directly, while current Playthings exposes `data-visible-moment-count` and a Root Gate interaction model.
- Prior Prism Major 002 evidence passed Verse-local/package/node integration gates but could not start the real React/Vite browser path in that execution host because the locked dependency tree was unavailable.

These are starting observations to qualify, not pre-authorized implementation conclusions.

## Dependencies

- Current repository-local Playthings orchestration frontier.
- Prior Prism Major 002 browser-reality Evidence and return Handoff.
- Exact carried App, Core and Site source snapshots.
- Current Prism Role in Business as the recipient capacity.

## Acceptance Boundary

Technical/browser PASS does not equal Sigma acceptance. Sigma retains the human experience judgment after a real candidate is made available.
